# 💜 Portfólio Interativo | Ana Beatriz

Este projeto é meu currículo e portfólio pessoal interativo, desenvolvido para apresentar minha trajetória acadêmica, experiências, competências e projetos na área de tecnologia.

O site combina uma identidade visual futurista, com tons de roxo e preto, animações e elementos interativos, proporcionando uma experiência de navegação dinâmica.

## ✨ Funcionalidades

- Interface responsiva com identidade visual personalizada.
- Circuitos eletrônicos animados durante a navegação.
- Efeito de digitação na apresentação pessoal.
- Seções de formação acadêmica, experiências e habilidades técnicas e interpessoais.
- Abas interativas para explorar experiências e atividades.
- Página dedicada a projetos de eletrônica, com vídeos demonstrativos.
- Animação de um carro de Fórmula 1 desenvolvida com SVG e CSS.
- Links para redes profissionais e projetos.

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, responsividade e animações.
- **JavaScript:** interatividade e efeitos dinâmicos.
- **SVG:** elementos gráficos e circuitos animados.

## 🎯 Objetivo

Criar um espaço que vá além de um currículo tradicional, reunindo minhas experiências em Engenharia de Software, desenvolvimento web, pesquisa científica e sistemas embarcados.

O projeto também representa a aplicação prática dos meus conhecimentos em desenvolvimento front-end, unindo programação, criatividade e design.
